# 김재현 — 나를 소개하는 사이트와 계속 새로 쓰는 장치

ALEPH 마지막 과제 A. 공개 사이트는 `index.html`, 문서(이력서·자기소개서·경력기술서)는 `docs/`, 새 기록으로 숫자와 문단 후보를 다시 만드는 장치는 `device/` 에 있습니다.

- 장치 사용법은 [device/README.md](device/README.md) 를 보세요. 입력 데이터(`data/`)는 개인 기록이라 이 저장소에 올리지 않았습니다.
- 사이트의 숫자와 인용은 장치가 입력 기록에서 계산한 결과이고, 사이트에 들어가는 문장은 `device/approved.json` 에서 사람이 승인한 것만입니다.
